# Relational Database Project – Databases Course (MSc Data Science, Centrale Lille)

This repository contains a course project completed for the **Databases** course in the MSc Data Science program at Centrale Lille (2025–2026).

The goal of the project was to design and implement a relational database starting from raw datasets, including:

* conceptual and logical data modeling,
* data cleaning and integration,
* database population using Python,
* and the design of meaningful SQL queries and database evolution scenarios.

---

## Project overview

**Course:** Databases (M1)

**Type:** Academic project (team of 2)

**Main objectives:**

* Transform raw CSV datasets into a structured relational database
* Design tables, attributes, primary and foreign keys, and constraints
* Handle missing and inconsistent data during ingestion
* Populate the database programmatically using Python
* Implement and analyze SQL queries of increasing complexity
* Propose realistic database modifications and extensions

---

## Dataset

The project is based on the following datasets:

* Dataset 1: `Oscars` (source: [link](https://www.kaggle.com/datasets/johnpendenque/oscars-from-1928-to-2024))
* Dataset 2: `Movies` (source: [link](https://www.kaggle.com/datasets/asaniczka/tmdb-movies-dataset-2023-930k-movies))

The data was originally provided as raw CSV files and required preprocessing and integration before being stored in a relational database.
